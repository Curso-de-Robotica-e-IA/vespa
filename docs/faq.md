# FAQ ❓

## 1️⃣ What is Vespa?
Vespa is a Python library designed for handling classification, regression, and detection tasks efficiently.

## 2️⃣ How do I install Vespa?
You can install Vespa via pip:
```bash
pip install vespa
```

## 3️⃣ What dataset formats does Vespa support?
Vespa supports **YOLO, COCO, and Pascal VOC** dataset formats.

## 4️⃣ Can I use Vespa with my custom dataset?
Yes, as long as it follows one of the supported formats.

## 5️⃣ How can I contribute to Vespa?
You can contribute by submitting issues, bug fixes, and feature enhancements through the [GitHub repository](https://github.com/my-username/vespa).
