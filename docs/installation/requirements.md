# System Requirements ✅

## 🖥️ Operating System
- Windows 10/11
- macOS (Monterey or later)
- Linux (Ubuntu 20.04+ recommended)

## 🛠️ Dependencies
- **Python 3.8+**
- **Poetry** (for dependency management)
- **MkDocs** (for documentation generation)

## 📦 Required Python Packages
Vespa requires the following packages, which will be installed automatically:
```bash
numpy
pandas
torch
scikit-learn
opencv-python
```

For a complete list, check `pyproject.toml`.
