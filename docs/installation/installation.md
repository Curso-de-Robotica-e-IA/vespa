# Installation Guide 🚀

This guide explains how to install and set up the Vespa library on your system.

## 1️⃣ Prerequisites
Before installing, ensure you have:
- **Python 3.12+** installed (`python --version`)
- **Poetry** for dependency management (`pip install poetry`)

## 2️⃣ Install the Library
The Vespa library is available via PyPI. Install it using:
```bash
pip install vespa
```

Or, if using Poetry:
```bash
poetry add vespa
```

## 3️⃣ Verify Installation
Check if Vespa is installed correctly by running:
```bash
python -c "import vespa; print(vespa.__version__)"
```

For more details on using the library, check the [Usage Guide](../usage/setup.md).
