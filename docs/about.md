# About 📌

Vespa is an open-source Python library designed to facilitate **classification, regression, and object detection** tasks.

### Features:
- 🖼️ Supports multiple dataset formats (YOLO, COCO, Pascal VOC)
- 🚀 Optimized for performance and scalability
- 🔌 Simple API for training and inference
