# Datasets Overview 📊

This section provides an overview of the datasets supported by Vespa for training and evaluation.

## 📌 Available Datasets
- **YOLO Format** - Used for object detection and classification.
- **COCO Format** - A large-scale dataset for object detection, segmentation, and captioning.
- **Pascal VOC Format** - A widely-used dataset for object detection.

Each dataset format has specific annotations and structure. See the individual dataset pages for more details:
- [YOLO Format](yolo.md)
- [COCO Format](coco.md)
- [Pascal VOC Format](pascal_voc.md)
